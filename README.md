# 🌌 The Architect of Worlds

> *Every world tells a story. Every story is a part of me.*

![Banner](./public/thumbnail.png)

## Overview

The Architect of Worlds is an immersive cinematic 3D website that transforms traditional web navigation into an interactive journey through handcrafted planets.

Visitors explore floating worlds instead of clicking through pages, creating a memorable experience inspired by science fiction, fantasy, and digital art.

---

## ✨ Features

- 🌍 Interactive planets
- 🎥 Cinematic camera animations
- ✨ Real-time particle systems
- 🌌 Dynamic space environment
- 💡 HDR lighting
- 🎨 Post-processing effects
- 🎵 Ambient soundtrack
- 📱 Responsive experience
- 🚀 Optimized performance
